# 🚀 OmniRoute — دروازه رایگان هوش مصنوعی

**ساختهشده توسط [Diego Souza](https://github.com/diegosouzapw)**

<img src="./docs/diagrams/readme-hero.svg" width="100%" alt="OmniRoute — هرگز کدنویسی را متوقف نکنید. هر ابزار هوش مصنوعی → 394 ارائهدهنده — 150+ مورد رایگان — از طریق یک endpoint. Claude Code، Codex، Cursor، Cline، Copilot و Antigravity به Claude / GPT / Gemini رایگان با بازگشت خودکار. فشردهسازی ترکیبی RTK + Caveman، 15–95٪ از توکنها (~89٪ بهطور میانگین) را ذخیره میکند — هرگز به محدودیتها نرسید. 394 ارائهدهنده هوش مصنوعی · 150+ سطح رایگان · ~1.62B توکن رایگان در ماه · 22 راهبرد مسیریابی · شروع با $0."/>

## 💰 ~۱.۶۲ میلیارد توکن / ماه در سطوح رایگان ارائهدهندگان شخص ثالث

</div>

> **حسابهای ارائهدهنده خودتان را بیاورید.** این مقدار، برآوردی تجمیعی از سطوح رایگان شخص ثالثی است که هرکدام بهصورت جداگانه واجد شرایط هستند، و کمکهزینه توکن از طرف OmniRoute نیست. ثبتنام کنید، در صورت نیاز اطلاعات احراز هویت دریافت کنید و ارائهدهندگانی را که میتوانید استفاده کنید متصل کنید؛ هر ارائهدهنده محدودیتها، دسترسپذیری و شرایط خود را کنترل میکند.
>
> کنار هم گذاشتن دستی سطوح رایگان دردسرساز است — دهها SDK، دهها محدودیت نرخ و هیچ ایدهای از میزان واقعی موجودی. OmniRoute، **۴۶۵ ورودی سطح رایگان در ۳۴ کلید استخر تکرارشونده** را فهرست میکند و مقدار اصلی توکن را از **۱۷ استخر دارای بودجه ماهانه مثبت و منتشرشده، بهعلاوه پنج سقف Groq برای هر مدل** محاسبه میکند؛ این محاسبه بر اساس استخر مشترک، حذف موارد تکراری انجام میشود. سهمیههایی که تنها پس از بررسی هویت منطقهای فعال میشوند (امروز: ModelScope) جداگانه نمایش داده میشوند، +~۶ میلیون پشت تأیید هویت منطقهای قرار دارند و هرگز در مقدار اصلی جمع نمیشوند. نتیجه در داشبورد (`/dashboard/free-tiers`) قابل مشاهده باقی میماند.

<img src="./docs/diagrams/free-tier-budget.svg" width="100%" alt="کارت بودجه سطح رایگان OmniRoute: ~۱.۶۲ میلیارد توکن رایگان در ماه بهصورت پایدار، و تا ~۲.۲۲ میلیارد در ماه اول با اعتبار ثبتنام، از ۳۴ کلید استخر تکرارشونده مستند که ۴۶۵ ورودی سطح رایگان فهرستشده را پشت یک نقطه پایانی پوشش میدهند. محاسبه صادقانه و مبتنی بر حذف موارد تکراری استخر — هر استخر مشترک تنها یکبار محاسبه میشود، از جمله ۱۷ استخر تکرارشونده با بودجه ماهانه مثبت و منتشرشده توکن، بهعلاوه پنج سقف Groq برای هر مدل؛ ۱۲ ارائهدهنده در فهرست ریسک شرایط با برچسب اجتناب مشخص شدهاند تا تصمیم با شما باشد. نوار بودجه شامل Mistral ۱ میلیارد، Nara ۲۱۰ میلیون، LLM7 ۱۵۰ میلیون، xKiro ۱۵۰ میلیون، Groq ۳۰ میلیون (پنج سقف برای هر مدل) و استخرهای کوچکتر است، بهعلاوه اعتبار ثبتنام ماه اول و ارائهدهندگان دائماً رایگان بدون سقف توکن که جداگانه نمایش داده میشوند تا مقدار اصلی را افزایش ندهند. میزان مصرفشده/باقیمانده زنده در /dashboard/free-tiers."/>

> خلاصه متحرک صفحه زنده `/dashboard/free-tiers`. روششناسی کامل (حذف موارد تکراری استخر، سطوح اعتبار، شرایط ارائهدهندگان): **[docs/reference/FREE_TIERS.md](docs/reference/FREE_TIERS.md)**.
>
> <sub>این ارقام هر دو هفته یکبار بر اساس فهرست زنده بازبینی میشوند و **در هر دو جهت تغییر میکنند** — اگر ارائهدهندهای سطح رایگان خود را پایان دهد، عدد کاهش مییابد؛ اگر ارائهدهنده جدیدی اضافه شود، افزایش پیدا میکند. ما همان چیزی را منتشر میکنیم که فهرست واقعاً محاسبه میکند، نه بهترین حالتِ گرد شده به بالا.</sub>

## 🆓 نصب کنید، یک ارائهدهنده را متصل کنید، سپس از طریق یک نقطه پایانی مسیریابی کنید

</div>

<img src="./docs/diagrams/works-zero-config.svg" width="100%" alt="سه مرحله: OmniRoute را نصب و راهاندازی کنید، یک ارائهدهنده واجد شرایط را با حساب کاربری یا کلید API خود متصل کنید، سپس ابزار خود را با استفاده از یک کلید API متعلق به OmniRoute و مدل auto به localhost:20128/v1 متصل کنید. مسیریابی به اتصالهای واجد شرایط موجود و محدودیتهای ارائهدهنده بستگی دارد."/>

```bash
# پس از اتصال یک ارائهدهنده، کلید OmniRoute خود را از Dashboard → Endpoints کپی کنید:
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer YOUR_OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

<sub>`auto` به یک مسیر واجد شرایط نیاز دارد. یک نصب تازه ممکن است هیچ مقصد واجد شرایطی بدون کلید نداشته باشد و یک ارائهدهنده بدون کلید ممکن است کلاینتهای شخص ثالث را رد کند. ارائهدهندگانی که با `tos: avoid` علامتگذاری شدهاند، از جمله Kiro، بهطور پیشفرض از مسیریابی خودکار مستثنا هستند؛ اتصال یک حساب این تنظیم را لغو نمیکند. پیش از انتخاب یک ارائهدهنده، [راهنمای سطوح رایگان](docs/getting-started/FREE-TIERS-GUIDE.md) را ببینید.</sub>

<sub>📦 اسکریپتهای شروع سریع قابل کپی و جایگذاری برای **Python، Node.js، PHP و cURL** → [`examples/quickstart/`](examples/quickstart/)</sub>

## 📡 رادار OmniRoute

عنوان اصلی سطح رایگان همچنان **~1.62B توکن در ماه** از کاتالوگ مستندشده و حذفتکرارشده بر اساس مخزن مشترک در بالا است. اعتبارهای موقت ثبتنام ارائهدهندگان میتوانند بهطور جداگانه میزان ماه اول را به **~2.22B** افزایش دهند. رادار یک لایهٔ اختیاری و امضاشده برای کاتالوگ است که برای افرادی طراحی شده که میخواهند در فاصلهٔ میان انتشار نسخههای OmniRoute، اطلاعات بهروزتری دربارهٔ دسترسپذیری مدلهای رایگان داشته باشند؛ کاتالوگ جامعه و تمام قابلیتهای رایگان موجود همچنان رایگان باقی میمانند.

حامیان میتوانند کاتالوگ زنده و فرصتهای بیشتری از ارائهدهندگان دریافت کنند. سقف جداگانه و متغیر آن، بسته به دسترسپذیری ارائهدهندگان، **حداکثر تقریباً 3B توکن در ماه** است. این سقف تضمینشده نیست: ارائهدهندگان ممکن است سهمیهها، شرایط احراز صلاحیت، مدلها یا مناطق را در هر زمان تغییر دهند.

رادار نیازمند فعالسازی اختیاری است و فقط از GET استفاده میکند. کلاینت OmniRoute هیچیک از اعلانها، ترافیک، پیکربندی ارائهدهنده، تلهمتری استفاده یا وضعیت محلی رد کردن اعلانها را آپلود نمیکند. برای آگاهی از شرایط احراز صلاحیت و کاتالوگ فعلی، به **[radar.omniroute.online/planos](https://radar.omniroute.online/planos)** مراجعه کنید.

**هر CLI پشتیبانیشده را تنها با یک فرمان از طریق OmniRoute اجرا کنید** — بدون نیاز به نوشتن فایل پیکربندی،
اعتبارنامهها به صورت جداگانه برای هر پردازش تزریق میشوند، Qwen/Gemini یک home ایزوله و موقت دریافت میکنند:

```bash
omniroute run claude   --model openai/gpt-5.4          # Claude Code
omniroute run codex    --model glm/glm-5.2             # OpenAI Codex CLI
omniroute run aider    --model glm/glm-5.2 -- --message "reply OK"
omniroute run goose    --model glm/glm-5.2
omniroute run opencode --model glm/glm-5.2 -- run "reply OK"
omniroute run qwen     --model glm/glm-5.2 -- -p "reply OK"
omniroute run gemini   --model glm/glm-5.2 -- --skip-trust -p "reply OK"

# یا ارائهدهنده و مدل را به صورت تعاملی انتخاب کنید و پیکربندی اختصاصی ابزار را بنویسید:
omniroute configure codex          # همچنین: claude opencode qwen aider goose gemini cline continue kilo 5dive
```

هر فرمان به context فعال remote (`omniroute connect <host>`) احترام میگذارد، `--dry-run`
پیشنمایشی از محیط و آرگومانها بدون اجرا ارائه میدهد، و `--api-key-env NAME` کلیدهای محرمانه را
از تاریخچه shell شما دور نگه میدارد. → [ادغامهای CLI](docs/guides/CLI-INTEGRATIONS.md)

### 🎩 جدید: OmniRouteTray — دروازه شما، زندگی در نوار منو

</div>

> `omniroute serve` وقتی همیشه روشن باشد خوشحال است.** [OmniRouteTray](https://github.com/zoispag/omniroute-tray)** آن را به یک برنامه نوار منوی تنظیم و فراموش کردن برای macOS تبدیل میکند: سرور را راهاندازی میکند، آن را در طول راهاندازی مجدد زنده نگه میدارد، آن را در جای خود بهروزرسانی میکند و بودجه رمز زنده شما را با یک کلیک دورتر از — قرار میدهد.** بدون پنجره ترمینال باز مانده است، هیچ `npm install -g omniroute` برای نگهداری از کودک.**

ساخته شده با [Tauri v2](https://v2.tauri.app/) (هسته Rust به اندازه یک خطای گرد کردن)، زمان اجرا Node 24 امضا شده خود را ارسال می کند و نصب OmniRoute متعلق به برنامه را مدیریت می کند، بنابراین هرگز با `node`/`bun` جهانی شما مبارزه نمی کند. آن را** پیکربندی `~/.omniroute/` و پایگاه داده موجود شما را به اشتراک می گذارد** — پس همان OmniRoute است که قبلاً اجرا میکردید، فقط با یک کلاه. 🎩

### 🛰️ حالت راه دور — اجرای CLI در اینجا و OmniRoute روی یک VPS

OmniRoute روی یک سرور است؟ با همان **CLI** از لپتاپ خود آن را کنترل کنید. یکبار
با یک توکن دسترسی دارای محدوده وارد شوید؛ سپس هر فرمانی به مقصد راه دور ارسال میشود.

```bash
omniroute connect 192.168.0.15            # گذرواژه → توکن دارای محدوده، ذخیرهشده بهعنوان یک زمینه
omniroute models                         # ← در برابر سرور راه دور اجرا میشود
omniroute configure codex                 # ← یک مدل راه دور را انتخاب کرده و یک نمایه محلی Codex مینویسد
omniroute tokens create --name ci --scope read   # توکنهای محدودتر برای ماشینهای دیگر ایجاد میکند
omniroute contexts use default            # ← بازگشت به سرور محلی
```

average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%

### 🎚️ فراتر از سبکهای خروجی — موتور، شمارهگیر تطبیقی و کنترل هر درخواست

12 موتور بالا آنچه را که می رود کوچک می کنند** در** . سه لایه دیگر شکل می گیرد** چگونه** ،** چه زمانی** ، و آنچه می آید** بیرون** :

- **سبک های خروجی 🪄** _(فرمان محور خروجی)_ دستورالعملهای شکلدهی پاسخ قطعی و ایمن در حافظه پنهان — تزریق میکند. قابل ترکیب، هر کدام در شدت `lite` / `full` / `ultra`. افزودن یک سبک یک ورودی رجیستری یک خطی است:
  - **نثر کوتاه** پرکننده قطره — / مقالات / پرچین; مواد فنی را دقیق نگه دارید
  - **کد کمتر** — "توسعه ارشد تنبل" YAGNI: کوچکترین تغییر کاری، بدون داربست درخواستی.
  - **دم اسبی (طرفدار ارشد تنبل)** — از نردبان YAGNI بالا بروید، علت اصلی را برطرف کنید، کوچکترین تفاوت کاری.
  - **من ADHD دارم (اول اقدام)** — اقدام بعدی منجر می شود، مراحل شماره گذاری شده، یک مرحله بعدی مشخص، بدون مقدمه.
  - **ترسه CJK (文言)** — کلاسیک-چینی سبک فوقالعاده مختصر (محلی-دردار به `zh`).
- **🎯 بافت-بودجه تطبیقی** _(شماره گیری)_ — به جای یک آستانه رمز on/off ، ارزان ترین و کم ضررترین موتورها را فقط تا جایی که لازم است افزایش دهید.** متناسب با پنجره زمینه مدل** . خط مشی: `reserve-output` (پیش فرض، مدل آگاه) · `percentage` · `absolute`. حالت: `floor` (ضمانت تناسب) · `replace-autotrigger` (انتخاب صریح شما برنده است) · `off` (آستانه میراث).
- **🎛️ جایی که فشرده سازی تصمیم می گیرد** _(اولویت، → زیاد کم)_ — در هر درخواست سرصفحه `x-omniroute-compression` › نادیده گرفتن مسیریابی- ترکیبی › نمایه با نام فعال › تطبیقی / فعال کننده خودکار › پیش فرض پانل › خاموش. طرح اعمال شده در هدر پاسخ `X-OmniRoute-Compression: <mode>; source=<source>` بازتاب می یابد.

راهاندازی خودکار با آستانه رمز، چرخاننده تطبیقی را برگردانید، نمایهای نامگذاری شده را پین کنید، برای هر درخواست یک بار تنظیم کنید، یا یک خط لوله را به ازای هر مسیریابی ترکیبی — تعیین کنید که با حجم کار مطابقت دارد. انتخاب آفلاین** مهار** (`npm run eval:compression`) قبل از اینکه تغییری را تبلیغ کنید، وفاداری در مقابل پس انداز را در یک پیکره سنجاق شده امتیاز می دهد.

**1) نصب و اجرا کنید**

```bash
npm install -g omniroute
omniroute
```

> 💡 هشدارهای `npm warn ERESOLVE` یا peer-dep را ببینید؟ [آنها بی ضرر هستند](docs/guides/TROUBLESHOOTING.md#npm-install-warnings-eresolve--peer--deprecated)** از npm 11 یا بالاتر استفاده می کنید؟** npm ممکن است اسکریپت های چرخه عمر بسته را مسدود کند مگر اینکه مجاز باشند. OmniRoute `postinstall` (`node scripts/build/postinstall.mjs`) برای آماده سازی فایل های زمان اجرا بومی آن مورد نیاز است. هنگام نصب جهانی، بستههای نامگذاری شده در هشدار npm را مجاز کنید. برای مجموعه بسته گزارش شده توسط OmniRoute 3.8.55:
>
> `bash npm install -g --allow-scripts=omniroute,keytar,onnxruntime-node,@parcel/watcher,@swc/core,protobufjs,esbuild omniroute `
>
> برای استفاده مجدد از این لیست مجاز برای نصب های جهانی آینده، آن را یک بار پیکربندی کنید، سپس به طور معمول نصب کنید:
>
> `bash npm config set allow-scripts=omniroute,keytar,onnxruntime-node,@parcel/watcher,@swc/core,protobufjs,esbuild --location=user npm install -g omniroute `
>
> لیست وابستگی می تواند بین نسخه ها تغییر کند. اگر npm لیست دیگری را گزارش کرد، از نام بسته های آن هشدار استفاده کنید. اجازه دادن به یک بسته به اسکریپت های نصب آن اجازه اجرا می دهد.** از Gemini Web یا دیگر ارائه دهنده کوکی وب استفاده می کنید؟** بسته npm شامل Playwright است اما نه باینری Chromium آن. قبل از ارائه اولین درخواست ارائهدهنده وب، یادداشت [راهاندازی Playwright Chromium](docs/guides/TROUBLESHOOTING.md#gemini-web-and-playwright-chromium) را ببینید.

داشبورد در `http://localhost:20128` · API در `http://localhost:20128/v1`.

**2) یک ارائه دهنده واجد شرایط را با استفاده از حساب شخصی خود وصل کنید**

داشبورد →** ارائه دهندگان** → ارائهدهندهای را انتخاب کنید که شرایط فعلی و سهمیهاش متناسب با مورد استفاده شما باشد. → کلید API را اضافه کند یا جریان حسابش را کامل کند. سطوح رایگان ممکن است نیاز به ثبت نام، تأیید یا روش پرداخت داشته باشند. [راهنمای ردیف های رایگان](docs/getting-started/FREE-TIERS-GUIDE.md) را مرور کنید. در دسترس بودن بدون کلید تضمین نمی شود و ارائه دهندگانی که `tos: avoid` علامت گذاری شده اند به طور پیش فرض از `auto` مستثنی هستند.

**3) به ابزار کدنویسی خود اشاره کنید**

```txt
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto            (routes among eligible connections — or choose provider/model)
```

**4) بررسی کنید که کار می کند**

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

شما باید مدل های متصل خود را در لیست مشاهده کنید. 🎉 همین است. — شروع به کدنویسی می کند و OmniRoute مسیرهای خودکار را برای شما انجام می دهد.

اگر مشتری شما نمی تواند هدرهای سفارشی ارسال کند، OmniRoute نام مستعار سازگاری توکن شده را نیز نشان می دهد:

```txt
OpenAI catalog:   http://localhost:20128/vscode/YOUR_KEY/
OpenAI models:    http://localhost:20128/vscode/YOUR_KEY/models
OpenAI chat:      http://localhost:20128/vscode/YOUR_KEY/chat/completions
OpenAI responses: http://localhost:20128/vscode/YOUR_KEY/responses
Ollama chat:      http://localhost:20128/vscode/YOUR_KEY/api/chat
Ollama tags:      http://localhost:20128/vscode/YOUR_KEY/api/tags
```

از اینها فقط برای مشتریانی استفاده کنید که نمی توانند `Authorization: Bearer ...` وصل کنند. Header auth حالت ترجیحی باقی می ماند.

## 📦 روش های نصب بیشتر — Docker, source, pnpm, Arch

**🐳 Docker**

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

`:latest` بالاترین را دنبال می کند** منتشر شده است** ثابت SemVer. git `main` را ردیابی نمی کند. پین `:X.Y.Z` برای GitOps. به [کانالهای انتشار Docker](docs/guides/DOCKER_GUIDE.md#release-channels) مراجعه کنید. پینهای تصویر**`OMNIROUTE_MEMORY_MB=1024`** . این برای داشبورد و یک چت سبک کافی است.** عوامل کدنویسی** (`POST /v1/responses` از کد Claude ، Codex، Grok، ...) به یک پشته V8 بسیار بزرگتر یا فرآیند `FATAL ERROR` در ~ 12 GiB تحت دو زمینه طولانی با هم همپوشانی نیاز دارید. اندازه ظرف را بالای پشته قرار دهید (بافرهای بومی خارج از V8 قرار دارند):

| حجم کار                          | هیپ (`-e OMNIROUTE_MEMORY_MB`) | ظرف (`--memory`) |
| -------------------------------- | ------------------------------ | ---------------- |
| داشبورد / چت سبک                 | `1024` (پیشفرض تصویر)          | ≥ 2 گرم          |
| یک عامل کد نویسی                 | `8192`                         | ≥ 10 گرم         |
| دو `/v1/responses` طولانی همزمان | `10240`–`12288`                | ≥ 12-16 گرم      |

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -e OMNIROUTE_MEMORY_MB=8192 --memory=10g \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

جدول کامل: [Docker Guide — runtime RAM](docs/guides/DOCKER_GUIDE.md#runtime-ram-for-coding-agents).

> **کانال Docker پیش از انتشار:** `diegosouzapw/omniroute:next` و `diegosouzapw/omniroute:next-web` از شاخه پیش فرض `release/v*` فعلی پیروی می کنند. این تگهای قابل تغییر فقط برای آزمایش رفعهای منتشر نشده در نظر گرفته شدهاند و هستند** برای تولید پشتیبانی نمی شود** . به [کانال های انتشار Docker](docs/guides/DOCKER_GUIDE.md#release-channels) مراجعه کنید.

**🥟 Bun**

نصب استاندارد `bun install` و جهانی (`bun install -g omniroute`) از طریق تشخیص زمان اجرا Bun پشتیبانی می شود:

- **`bun:sqlite` توکار** : OmniRoute هنگام اجرای زیر Bun از درایور `bun:sqlite` داخلی Bun استفاده میکند و در Node.js یا `sql.js` به `better-sqlite3` برمیگردد.
- **انتخاب خودکار باندلر Webpack در توسعه دهنده** : توسعه (`bun run dev`) به طور خودکار Bun شناسایی می کند و Turbopack به نفع Webpack غیرفعال می کند تا از ناسازگاری های اتصال V8 بومی جلوگیری کند. ساختهای تولیدی (`bun run build`) دقیقاً مانند Node از `OMNIROUTE_USE_TURBOPACK` پیروی میکنند: Turbopack به طور پیشفرض، `OMNIROUTE_USE_TURBOPACK=0` برای ساخت با Webpack (`Dockerfile.bun` آن را به عنوان `--build-arg` نشان میدهد).
- **اختصاصی Bun Dockerfile** : `Dockerfile.bun` چند مرحله ای برای استقرار تولید Bun بومی (`docker build -f Dockerfile.bun -t omniroute:bun .`).

```bash
# Install and run with Bun
bun install
bun run dev
```

**نصب سریعتر / ناب ⚡ (از ساخت بومی صرفنظر کنید)**

موتور SQLite بومی (`better-sqlite3`) یک است** اختیاری** وابستگی، بنابراین یک نصب سراسری هرگز کامپایل از منبع را مسدود نمی کند: زمانی که با platform/Node شما مطابقت دارد از یک باینری از پیش ساخته شده استفاده می کند و در غیر این صورت به طور شفاف به یک موتور خالص JS (`node:sqlite` در Node 22 +، در غیر این صورت `sql.js` WASM همراه) — بدون نیاز به ابزار ساخت برمی گردد.

برای رد شدن از نصب پس از نصب** گرم کردن بومی** به طور کامل (CI، ماشین های بدون سر یا کند). توجه: این فقط مرحله گرم کردن SQLite بومی (`scripts/postinstall.mjs`) را رد می کند. قلاب binary-copy/repair (`scripts/build/postinstall.mjs`) هنوز به طور معمول کار می کند:

```bash
OMNIROUTE_SKIP_POSTINSTALL=1 npm install -g omniroute   # CI=1 also skips it
```

برای سریع ترین نصب ترجیح می دهند** pnpm** (لینکهای سخت + فروشگاه آدرسدهی محتوا — را در بالا ببینید). برای یک زمان اجرا بدون داشبورد و بدون هد از نمایه Docker `base` (بالا) یا [راهنمای Termux](docs/guides/TERMUX_GUIDE.md) استفاده کنید. CLI و داشبورد وب با فرآیند یکسانی در یک پورت ارائه میشوند، بنابراین امروزه بستهای جداگانه برای CLI وجود ندارد.

### نحوهٔ مشارکت

1. مخزن را fork کنید
2. از نوک فعال `release/vX.Y.Z` (نه `main`) یک شاخه ایجاد کنید — به [مدل شاخهبندی و انتشار](docs/ops/BRANCHING_MODEL.md) مراجعه کنید
3. شاخهٔ قابلیت خود را ایجاد کنید (`git checkout -b feat/amazing-feature`)
4. تغییرات خود را commit کنید (`git commit -m 'feat: add amazing feature'`)
5. به شاخه push کنید (`git push origin feat/amazing-feature`)
6. یک Pull Request با **base = آن شاخهٔ `release/vX.Y.Z`** باز کنید

برای مشاهدهٔ دستورالعملهای کامل، به [CONTRIBUTING.md](CONTRIBUTING.md) مراجعه کنید.

# ایجاد یک انتشار — npm publish بهصورت خودکار انجام میشود
VERSION=x.y.z
gh release create "v${VERSION}" --title "v${VERSION}" --generate-notes

## 🙏 قدردانی

</div>

OmniRoute بر شانههای غولها ایستاده است. این پروژه بهعنوان یک فورک از **[9router](https://github.com/decolua/9router)** و یک پورت TypeScript از پروژه Go یعنی **[CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI)** آغاز شد — و از آنجا، هر زیرسیستم زیر از یک پروژه متنباز که زودتر به این مسیر رسیده بود الهام گرفت. هرکدام بخش مشخصی از OmniRoute را شکل دادند. این ادای تشکر ما از همه آنهاست. 🙏

> ⭐ شمارش ستارهها با استفاده از REST API گیتهاب در ۳ نوامبر ۲۰۲۶ تأیید شده است — بروید و به این پروژهها ستاره بدهید. این شمارشها یک تصویر لحظهای دقیق در تاریخی مشخص هستند و طبیعتاً تغییر خواهند کرد.
