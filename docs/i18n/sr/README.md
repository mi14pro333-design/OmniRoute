## 💰 ~1.62B tokena / mesečno kroz besplatne nivoe trećih strana

</div>

> **Koristite sopstvene naloge kod provajdera.** Ovo je procenjeni zbir zasebno dostupnih besplatnih nivoa trećih strana, a ne dodela tokena od strane OmniRoute-a. Registrujte se, pribavite akreditive gde je to potrebno i povežite provajdere koje možete da koristite; svaki provajder kontroliše svoja ograničenja, dostupnost i uslove.
>
> Ručno kombinovanje besplatnih nivoa je naporno — na desetine SDK-ova, na desetine ograničenja brzine i bez jasne predstave o tome koliko zapravo imate. OmniRoute katalogizuje **465 stavki besplatnih nivoa kroz 34 ključa ponavljajućih skupova** i izračunava naslovnu vrednost tokena iz **17 skupova sa objavljenim pozitivnim mesečnim budžetom, uz pet Groq ograničenja po modelu**, deduplikovanih prema deljenom skupu. Kvote koje se otvaraju tek nakon regionalne provere identiteta (danas: ModelScope) prikazane su odvojeno, +~6M nakon regionalne verifikacije identiteta, i nikada se ne sabiraju u naslovnu vrednost. Rezultat je i dalje vidljiv na kontrolnoj tabli (`/dashboard/free-tiers`).

<img src="./docs/diagrams/free-tier-budget.svg" width="100%" alt="Kartica besplatnog budžeta OmniRoute-a: ~1.62B besplatnih tokena mesečno u kontinuitetu, do ~2.22B tokom prvog meseca uz kredite za registraciju, iz 34 dokumentovana ključa ponavljajućih skupova koji obuhvataju 465 katalogizovanih stavki besplatnih nivoa iza jedne krajnje tačke. Pošten obračun sa deduplikacijom skupova — svaki deljeni skup uračunat je jednom, uključujući 17 ponavljajućih skupova sa objavljenim pozitivnim mesečnim budžetom tokena i pet Groq ograničenja po modelu; 12 provajdera označeno je kao izbegavati u katalogu rizika uslova, pa vi odlučujete. Traka budžeta obuhvata Mistral 1B, Nara 210M, LLM7 150M, xKiro 150M, Groq 30M (pet ograničenja po modelu) i manje skupove, uz kredite za registraciju tokom prvog meseca i provajdere koji su trajno besplatni bez ograničenja broja tokena, prikazane odvojeno tako da nikada ne uvećavaju naslovnu vrednost. Trenutno iskorišćeno/preostalo na /dashboard/free-tiers."/>

> Animirani pregled stranice `/dashboard/free-tiers` uživo. Kompletna metodologija (deduplikacija skupova, nivoi kredita, uslovi provajdera): **[docs/reference/FREE_TIERS.md](docs/reference/FREE_TIERS.md)**.
>
> <sub>Ove brojke se ponovo proveravaju svake dve nedelje u odnosu na katalog uživo i **mogu da se menjaju u oba smera** — provajder ukine besplatni nivo i broj opadne; pojavi se novi i broj poraste. Objavljujemo ono što katalog zaista izračuna, a nikada naviše zaokružen najbolji mogući slučaj.</sub>

## 🆓 Instalirajte, povežite provajdera, a zatim usmeravajte kroz jednu krajnju tačku

</div>

<img src="./docs/diagrams/works-zero-config.svg" width="100%" alt="Tri koraka: instalirajte i pokrenite OmniRoute, povežite podobnog provajdera pomoću sopstvenog naloga ili API ključa, a zatim usmerite svoj alat na localhost:20128/v1 koristeći OmniRoute API ključ i model auto. Usmeravanje zavisi od dostupnih podobnih veza i ograničenja provajdera."/>

```bash
# Nakon povezivanja provajdera, kopirajte svoj OmniRoute ključ iz kontrolne table → krajnje tačke:
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer YOUR_OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

<sub>`auto` zahteva podobnu rutu. Sveža instalacija možda nema nijedno podobno odredište bez ključa, a provajder koji ne zahteva ključ može odbiti klijente trećih strana. Provajderi označeni sa `tos: avoid`, uključujući Kiro, podrazumevano su isključeni iz automatskog usmeravanja; povezivanje naloga ne menja tu postavku. Pogledajte [Vodič kroz besplatne nivoe](docs/getting-started/FREE-TIERS-GUIDE.md) pre nego što izaberete provajdera.</sub>

Слој 1: прекидач кола добављача (цео добављач): активира се само за 408/5xx, прагови су OAuth 8× / API-key 12× / local 2×, ресетује се после 60s/30s/15s у пробни режим HALF-OPEN, уз лењи опоравак; док је OPEN, комбинација преусмерава захтев на следећег добављача. ## 📡 OmniRoute Radar

Главна бројка за бесплатни ниво остаје **~1,62 млрд. токена месечно** из горе наведеног документованог
каталога, из ког су уклоњена преклапања између група. Привремени кредити за регистрацију код добављача могу засебно повећати обим током првог
месеца на **~2,22 млрд.** Radar је опционални, потписани слој каталога за кориснике који желе ажурнију
доступност бесплатних модела између OmniRoute издања; каталог заједнице и све постојеће бесплатне
функционалности остају бесплатни.

Подржаваоци могу добити актуелни каталог и додатне могућности добављача. Његова засебна,
променљива горња граница износи **највише приближно 3 млрд. токена месечно**, у зависности од доступности добављача.
Та горња граница није загарантована: добављачи могу у било ком тренутку променити квоте, услове испуњавања, моделе или регионе.

Radar се користи по избору и подржава само GET. OmniRoute клијент не отпрема упите, саобраћај, конфигурацију
добављача, телеметрију коришћења нити локално стање одбацивања обавештења. Сазнајте више о условима испуњавања и
актуелном каталогу на **[radar.omniroute.online/planos](https://radar.omniroute.online/planos)**.

```bash
omniroute run claude   --model openai/gpt-5.4          # Claude Code

omniroute run aider    --model glm/glm-5.2 -- --message "reply OK"

```

## 🔌 Потпуни CLI + A2A и MCP

</div>

> Поред сервера, OmniRoute је **потпуна командна контролна табла** са **више од 80 команди**, као и отвореним протоколима за агенте, тако да AI агент може да управља њиме **самостално**.

### ⌨️ Прави CLI (не само `start`)

```bash
omniroute               # покреће gateway + контролну таблу (порт 20128)
omniroute chat          # интерактивни TUI клијент за ћаскање (косе црте: /model /combo /skill /memory)
omniroute setup         # вођени чаробњак за прво покретање
omniroute doctor        # дијагностикује провајдере, портове и изворне зависности
```

### 🛰️ Удаљени режим — покрените CLI овде, а OmniRoute на VPS-у

OmniRoute на серверу? Управљајте њиме са свог лаптопа користећи **исти CLI**. Пријавите се једном
са токеном за приступ ограниченог опсега; свака команда ће затим бити усмерена на удаљени сервер.

```bash
omniroute connect 192.168.0.15            # лозинка → токен ограниченог опсега, сачуван као контекст
omniroute models                         # ← покреће се над УДАЉЕНИМ сервером
omniroute configure codex                 # ← бира удаљени модел, уписује локални Codex профил
omniroute tokens create --name ci --scope read   # креира уже токене за друге машине
omniroute contexts use default            # ← враћа се на локални сервер
```

Опсези токена су `read` / `write` / `admin`; руте које покрећу процесе остају доступне само преко loopback-а.

### 📖 Како функционише — цевовод, архитектура и математика уштеде

<img src="./docs/diagrams/compression-pipeline.svg" width="100%" alt="OmniRoute compression pipeline: an illustrative 10,000-token client request passes through 12 composable engines — Session-Dedup, CCR, Lite, RTK, Responses Tool Output, Headroom, Relevance, Caveman, Aggressive, LLMLingua-2, Ultra and OmniGlyph — and can reach the provider at about 1,080 tokens in the documented stacked example. Structured content is protected by preservation guards and per-step fidelity gates; explicit lossy or experimental modes may transform eligible content."/>

Подразумевана наслагана комбинација покреће `RTK → Caveman`. Када оба делују на исти tool/context носивост, уштеда је:

```txt
combined = 1 − (1 − RTK) × (1 − Caveman_input)
average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%
range    = 78.4 – 94.6%
```

Блокови кода, URLs, JSON и структурирани подаци су** увек заштићен** помоћу мотора за очување.

> **Зашто користити много жетона када само неколико жетона ради трик?** Сваки захтев пролази кроз OmniRoute компресијски цевовод** транспарентно** — нема промена клијента. Сада је а** сноп од 12 композитних мотора** који раде по редоследу и мешају и поклапају по рутној комбинацији — на основу идеја [RTK](https://github.com/rtk-ai/rtk), [Цавеман](https://github.com/JuliusBrussee/caveman) (⭐ 90К +), [LLMLingua-2](https://github.com/microsoft/LLMLingua) и [Троглодита](https://github.com/leninejunior/troglodita) (ПТ-БР).

### 🎚️ Поред покретача — излазних стилова, прилагодљиво бирање и контрола по захтеву

12 мотора изнад смањују оно што иде** ин** . Облик још три слоја** како** ,** када** , и шта долази** оут** :

- **🪄 Излазни стилови** _(управљање излазном осовином)_ — убаци детерминистичке, кеш-безбедне инструкције за обликовање одговора; могу се комбиновати, сваки при `lite` / `full` / `ultra` интензитету. Додавање стила је унос у регистру у једном реду:
  - **Кратка проза** — дроп филлер / артикли / хеџинг; одржавати тачност техничке супстанце.
  - **Мање кода** — "лењи старији дев" YAGNI: најмања радна промена, без незахтевних скела.
  - **коњски реп (лењи старији програмер)** — попните се на YAGNI мердевине, поправите основни узрок, најмања радна разлика.
  - **Имам ADHD (прва акција)** — следећа радња води, кораци су нумерисани, један конкретан следећи корак, без преамбуле.
  - **Терсе CJK (文言)** — класично-кинески ултра кратак стил (лоцале-гатед то `zh`).
- **🎯 Прилагодљиви контекст-буџет** _(диал)_ — уместо једног прага on/off токена, ескалирајте најјефтиније машине без губитака само онолико колико је потребно да** одговара прозору контекста модела** . Политика: `reserve-output` (подразумевано, свесни модела) · `percentage` · `absolute`. Режим: `floor` (гарантовано уклапање) · `replace-autotrigger` (ваш експлицитни избор побеђује) · `off` (застарели праг).
- **🎛️ Где се одлучује о компресији** _(предност, висок → низак)_ — по захтеву `x-omniroute-compression` заглавље › рутирање-комбо замена › активни именовани профил › адаптивни / аутоматски окидач › панел подразумевано › искључено. Примењени план се враћа у `X-OmniRoute-Compression: <mode>; source=<source>` заглавље одговора.

Аутоматско окидање према прагу токена, окретање прилагодљивог точкића, закачење именованог профила, постављање једнократног по захтеву или додељивање цевовода по комбинацији рутирања — шта год одговара радном оптерећењу. Опт-ин ван мреже** евал харнесс** (`npm run eval:compression`) оцењује верност у односу на уштеду на закаченом корпусу пре него што промовишете промену.

Дозволите пакете именоване у нпм-овом упозорењу када се инсталирају глобално. За скуп пакета који је пријавио OmniRoute 3.8.55:

>

>
> Листа зависности може да се мења између издања; ако нпм пријављује другу листу, користите називе пакета из тог упозорења. Омогућавање пакету дозвољава покретање његових инсталационих скрипти.** Користите Gemini Веб или другог добављача веб колачића?** нпм пакет укључује Playwright, али не и његову Цхромиум бинарну датотеку. Погледајте белешку [о подешавању Playwright Цхромиум-а](docs/guides/TROUBLESHOOTING.md#gemini-web-and-playwright-chromium) пре него што упутите први захтев веб-провајдера.

Контролна табла на `http://localhost:20128` · API на `http://localhost:20128/v1`.

Дасхбоард →** Провајдери** → изаберите провајдера чији тренутни услови и квота одговарају вашем случају коришћења → додајте свој API кључ или довршите ток налога. Base URL: http://localhost:20128/v1

**4) Проверите да ли ради**

Користите их само за клијенте који не могу да прикаче `Authorization: Bearer ...`. Потврда заглавља остаје преферирани режим.

## 📦 Више метода инсталације — Docker, извор, пнпм, Арцх

**🐳 Docker**

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

`:latest` прати највиши** објављено** стабилан SemVer. Не прати гит `main`. Пин `:X.Y.Z` за GitOps. Погледајте [Docker Релеасе Цханнелс](docs/guides/DOCKER_GUIDE.md#release-channels). Игле за слику**`OMNIROUTE_MEMORY_MB=1024`** . То је довољно за контролну таблу и лагано ћаскање.** Агенти за кодирање** (`POST /v1/responses` из кода Claude, Codex, Grok, …) потребна је много већа В8 хрпа или процес `FATAL ERROR` с на ~ 12 GiB под два дуга контекста који се преклапају. Одредите величину контејнера изнад гомиле (природни бафери се налазе изван В8):

| Оптерећење посла                     | гомила (`-e OMNIROUTE_MEMORY_MB`) | Контејнер (`--memory`) |
| ------------------------------------ | --------------------------------- | ---------------------- |
| Контролна табла / светло ћаскање     | `1024` (подразумевана слика)      | ≥ 2 г                  |
| Један агент за кодирање              | `8192`                            | ≥ 10 г                 |
| Два истовремена дуга `/v1/responses` | `10240`–`12288`                   | ≥ 12–16 г              |

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -e OMNIROUTE_MEMORY_MB=8192 --memory=10g \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

Цела табела: [Docker Водич — рунтиме RAM](docs/guides/DOCKER_GUIDE.md#runtime-ram-for-coding-agents).

> **Docker канал пре објављивања:** `diegosouzapw/omniroute:next` и `diegosouzapw/omniroute:next-web` прате тренутну подразумевану грану `release/v*`. Ове променљиве ознаке су намењене само за тестирање необјављених поправки и јесу** није подржано за производњу** . Погледајте [Docker Релеасе Цханнелс](docs/guides/DOCKER_GUIDE.md#release-channels).

**🥟 Bun**

Стандардна `bun install` и глобална инсталација (`bun install -g omniroute`) су подржане преко Bun детекције времена извршавања:

- **Уграђени `bun:sqlite`** : OmniRoute користи уграђени Bun `bun:sqlite` када ради под Bun, враћајући се на `better-sqlite3` на Node.js или `sql.js`.

- **Наменски Bun Доцкерфиле** : Вишестепени `Dockerfile.bun` за примену Bun производње (`docker build -f Dockerfile.bun -t omniroute:bun .`).

**⚡ Бржа / лакша инсталација (прескочите изворну верзију)**

Изворни SQLite мотор (`better-sqlite3`) је ан** опционо** зависност, тако да глобална инсталација никада не блокира компајлирање из извора: користи унапред изграђену бинарну датотеку када се подудара са вашим platform/Node, а иначе се враћа транспарентно на чист ЈС мотор (`node:sqlite` на Ноде 22 +, иначе у пакету `sql.js` WASM) — нису потребни алати за прављење.

Да бисте прескочили пост-инсталацију** родно загревање** у потпуности (CI, безглаве или споре машине). Напомена: ово само прескаче изворни SQLite корак загревања (`scripts/postinstall.mjs`); binary-copy/repair кука (`scripts/build/postinstall.mjs`) и даље ради нормално:

```bash
OMNIROUTE_SKIP_POSTINSTALL=1 npm install -g omniroute   # CI=1 also skips it
```

За најбрже инсталације преферирајте** пнпм** (Адресирано на садржају продавница + хард линкс — види горе). За време рада без контролне табле, користите Docker `base` профил (изнад) или [Термук водич](docs/guides/TERMUX_GUIDE.md). CLI и веб контролна табла се опслужују истим процесом на једном порту, тако да данас не постоји посебан пакет само за ЦЛИ.

### Kako doprineti

1. Napravite fork repozitorijuma
2. Kreirajte granu na osnovu **aktivnog** vrha grane `release/vX.Y.Z` (ne grane `main`) — pogledajte [Model grananja i objavljivanja](docs/ops/BRANCHING_MODEL.md)
3. Kreirajte granu za funkcionalnost (`git checkout -b feat/amazing-feature`)
4. Komitujte izmene (`git commit -m 'feat: add amazing feature'`)
5. Pošaljite izmene na granu (`git push origin feat/amazing-feature`)
6. Otvorite zahtev za integraciju sa **base = tom granom `release/vX.Y.Z`**

Pogledajte [CONTRIBUTING.md](CONTRIBUTING.md) za detaljna uputstva.

### Objavljivanje nove verzije

```bash
# Kreirajte izdanje — npm publish se izvršava automatski
VERSION=x.y.z
```
